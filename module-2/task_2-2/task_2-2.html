1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Vi bruker const når verdien ikke skal endres, og let når verdien skal kunne endres senere. Nei, alle kan ikke være konstanter fordi noen verdier må kunne endres.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parenteser bestemmer hva som skal regnes ut først. Det som står inni parentesen blir regnet ut før resten.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. i kan bruke toFixed(). For eksempel gir toFixed(2) et resultat med to desimaler.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. Desimaltall kan ha små forskjeller. Vi kan derfor runde dem til samme antall desimaler før vi sammenligner dem.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Sammenligningsoperatorer returnerer true eller false. For eksempel gir 5 > 3 resultatet true.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() lager et tilfeldig desimaltall fra 0 og opp til, men ikke inkludert, 1. Det kan brukes til å lage tilfeldige tall.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. Modulus % finner resten etter en divisjon. For eksempel er 10 % 3 lik 1. Vi bruker den når vi vil finne ut hvor mye som er igjen etter en divisjon.
